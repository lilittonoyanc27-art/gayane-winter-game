# ❄️💗 El invierno mágico de Gayane

Уютная зимняя браузерная игра-симулятор: Гаяне живёт зимние дни в своей квартире и на улице и **изучает испанский язык через действия**. Весь интерфейс на испанском; перевод на армянский открывается только по нажатию.

## Игры

| # | Сцена | Механика |
|---|-------|----------|
| 1 | **¿Qué me pongo hoy?** 👗 | Гардероб из 14 вещей: перетаскивание на Гаяне перед зеркалом, вещи видны на ней. Погода (солнце, холод, снег, ветер) и поводы (прогулка, кафе, подруга, горы, свидание); проверка комплекта с объяснением ошибок. |
| 2 | **Preparamos chocolate caliente** ☕ | Готовка по шагам: выбор продуктов, наливание, добавление по счёту («dos cucharadas»), включение огня или духовки, помешивание пальцем, подача, украшение. Анимации жидкости, растворения, пара. Рецепты: chocolate, tostadas, té con limón, sopa, galletas, magdalenas. |
| 3 | **Decora tu habitación** 🏠 | Свободная расстановка мебели и декора с проверкой предлогов: *encima de, debajo de, al lado de, delante de, detrás de, entre*. Гаяне описывает, где стоит вещь. Есть режим свободного декора; расстановка сохраняется. |
| 4 | **Un día de nieve** ⛄ | Прогулка по улице (стрелки, клавиатура, нажатие на землю), сбор снежинок со словами, лепка снеговика (катать шары, ставить их друг на друга, украшать), снежки по цветам, фотоохота, киоск с напитками, разговор с подругой. |
| 5 | **Compras de invierno** 🛍️ | Список покупок, фраза у прилавка (собрать из слов или выбрать), корзина, диалог на кассе, оплата купюрами и монетами, подсчёт сдачи. |
| 6 | **Una tarde con amigas** 💕 | Уборка, сервировка стола (izquierda/derecha/delante/detrás), ветвящийся разговор с Лусией и Мартой: ответы меняют ход беседы и концовку. |
| 7 | **La mañana perfecta** 🌸 | Будильник, подъём, шторы и погода, заправить кровать, душ, одеться, завтрак, план дня. Упражнения на Presente, Pretérito perfecto, Indefinido, Imperfecto и Futuro в зависимости от уровня. |
| 8 | **El misterio del regalo** 🎁 | Шесть глав: загадки, поиск по комнатам, расшифровка записки, расспросы соседей (tú / usted), голосовое сообщение, добрый финал. |
| + | **Minijuegos** 🎲 | Memory, Escucha y encuentra, Completa el diálogo, Ordena la frase, ¿Qué falta?, Verdadero o falso, Corrige el error, ¿Qué harías tú? |

## Обучение
- Уровни **A1 · A2 · B1 · B2**: от уровня зависят задания, лексика и грамматика.
- **Нажмите на любой испанский текст**, чтобы увидеть армянский перевод. На кнопках: долгое нажатие или режим **«Ա»** в шапке.
- Кнопки **Escuchar / Traducir / Repetir** (медленнее) у каждой реплики; озвучка через Web Speech API (`es-ES`).
- Звёзды и прогресс сохраняются в `localStorage`.
- **Mi diccionario**: все услышанные и переведённые фразы. **Repasar**: карточки трудных фраз (ошибки попадают туда автоматически). В **Ajustes** есть сброс прогресса с подтверждением.

## Технологии
React 18 + TypeScript + Vite. Сцены сделаны на DOM/SVG с собственным drag-and-drop на Pointer Events (мышь и касание), звуки синтезируются через WebAudio, внешних ассетов нет.

```bash
npm install
npm run dev      # разработка
npm run build    # продакшн-сборка в dist/
```

### Деплой на Vercel
Импортируйте репозиторий в Vercel: фреймворк **Vite**, сборка `npm run build`, папка `dist` (уже указано в `vercel.json`).

> Для озвучки нужен браузер с испанским голосом (Chrome, Edge, Safari).
